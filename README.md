# Midnight Carvings

Modern & minimal Indian restaurant website built from scratch with:

- HTML
- CSS
- Vanilla JavaScript

## Run in VS Code

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Build order

The code is intentionally organized in steps:
1. Navigation
2. Hero
3. Features
4. Popular dishes
5. Story
6. Menu
7. Reservation
8. Gallery

Next we can replace placeholder content, improve the exact design, add menu filtering, and connect the reservation form to a backend/database.
